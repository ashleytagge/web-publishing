# NOTES — S04 · Type Scale

## Intent
A whimsical fairy garden with colorful, fluid headings, but body text that any person can see and read regardless of colored-vision impairment. The colors should be light and bright while still meeting accessibility contrast standards.

## AI use
I used AI to explore different font pairings that matches my theme. I had it test out a few different pairings so I could see them together before I ultimately decided on one. I asked it not to reccomened or use colors that would not meet accessibility standards.

## Accepted / changed / rejected
I rejected font suggestions like Dancing Script and Fredoka. I accepted Lora and Arial as fonts. I rejected the initial color scheme because it looked like barney, and I changed it to use blues, pinks, purples, and off white colors. I also reviewed and accepted a type scale.

## Dig deeper
To dig deeper I learned more about the rem-based type scale. I understand that type should have a scale, but the rem part is was confused me. I learned that when we use rem, the rules set heading sizes based on the root font size. This means that we can update the root font size to change both the heading and body text sizes because they're both set in rem.
