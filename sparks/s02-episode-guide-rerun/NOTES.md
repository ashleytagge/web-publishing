## Dig deeper
One thing I looked up (https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Table_accessibility) was how table accessibility works. I learned that using table captions are important and do improve accessibility, however its even better when you also make sure to use th for header cells, td for data cells, and scope for rows and columns. Screen readers use these identifiers to make connections between different cells and the information inside of them.
